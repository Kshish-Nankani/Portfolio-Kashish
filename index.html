CareerMap – Career Development Platform

CareerMap is a full-stack career development platform built with the MERN stack to help users explore career paths, assess their skills, connect with tutors, and access career-related services. The platform supports multiple user roles and provides secure authentication, real-time communication, cloud media management, and online payment functionality.

Key Features:

  • Role-Based Authentication: Separate access and functionality for Regular Users, Tutors, Sellers, and Admins.
  • Career Assessment: Rule-based career assessment system that evaluates user responses and suggests suitable career paths.
  • Tutor Services: Tutors can offer services through different subscription tiers, with users able to explore and purchase tutoring packages.
  • Real-Time Chat: Integrated Socket.IO for real-time communication between users and tutors.
  • Payment Integration: PayFast integration for online payments along with Cash on Delivery support.
  • Secure Authentication: JWT-based authentication with protected routes and role-based authorization.
  • Cloud Media Management: Cloudinary integration for uploading and managing profile and service images.
  • OTP & Email Notifications: Nodemailer-based email notifications and OTP verification.
  • Admin Dashboard: Administrative controls for managing users, tutors, sellers, and platform activities.
React.js Node.js Express.js MongoDB JWT Socket.IO Cloudinary Nodemailer PayFast
